
## Baseline — Phase 4 STEP 55.1
- دخول الطاقم: البريد الإلكتروني + كلمة المرور فقط.
- بطاقات الدخول تعرض البريد وكلمة المرور المؤقتة الفعلية عند إصدارها.
- كلمات المرور المؤقتة محفوظة في ذاكرة الصفحة فقط ولا تُخزّن في قاعدة البيانات بصيغة مكشوفة.
- الطباعة تطبع البطاقات الجاهزة فقط.
- بعد إعادة تحميل الصفحة يجب إصدار كلمة مرور جديدة إذا احتجت لطباعة بطاقة مرة أخرى.

# Solouki (سلوكي) — STEP 50

نظام إدارة السلوك والانضباط المدرسي وفق القرار الوزاري 150/2024.

## الإصدار
**4.50.3** — التكريمات + نظام النقاط (التحفيز التربوي)

## ما يشمله هذا الإصدار
- كل ما سبق حتى STEP 49 (متابعات + تصعيد + تنبيه كتابي)
- تسجيل تكريمات إيجابية مع نقاط
- رصيد سلوك (إيجابي − خصم مخالفات) في ملف الطالب وبوابة ولي الأمر
- تصنيفات تكريم جاهزة (قابلة للتوسعة)

## التشغيل السريع
1. نفّذ سكربت SQL بالترتيب عند الحاجة — آخرها: `sql/phase4-step50-merits-points.sql`
2. تأكد أن `js/config.js` يحتوي URL ومفتاح anon الصحيحين.
3. افتح `index.html` عبر استضافة ثابتة أو خادم محلي.
