## قواعد التقدم
1. لا ننتقل لـ STEP جديد قبل اعتمادك العملي للسابق.
2. كل STEP هدف واحد رئيسي.
3. التسليم = ZIP تراكمي كامل + CHANGELOG.
4. الأمان والصلاحيات قبل الميزات الجديدة عند التعارض.
