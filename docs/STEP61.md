# STEP 61 — طباعة تنبيه كتابي للتوقيع

## التاريخ
2026-09-17

## المطلوب
عند اختيار عقوبة «التنبيه الكتابي» يجب طباعة نموذج ورقي بكل التفاصيل ليوقّع عليه الطالب (أو مجموعة الطلاب المشاركين في واقعة واحدة).

## السلوك
### تسجيل فردي
- بعد الحفظ بعقوبة تنبيه كتابي: تأكيد للطباعة + زر في رسالة النجاح.
- النموذج: بيانات الطالب + المخالفة + إقرار وتوقيع الطالب وولي الأمر + توقيعات الطاقم.

### تسجيل جماعي
- بعد الحفظ: طباعة ورقة لكل طالب في السلة.
- كل ورقة تعرض قائمة المشاركين الآخرين في الواقعة مع خانة توقيع لكل منهم (على ورقة الطالب الحالي يظهر إقرار الطالب؛ والمشاركون في جدول منفصل).

### من جدول السجل
- زر «🖨️ تنبيه» يظهر فقط عندما تكون العقوبة تنبيه كتابي.

### ملف السلوك (student-report)
- نموذج «طباعة تنبيه كتابي» يتضمن إقرار الطالب وولي الأمر.

## اختبار
1. سجّل مخالفة فردية بعقوبة تنبيه كتابي → اطبع وراجع التوقيعات.
2. سجّل جماعي لـ 2–3 طلاب بنفس العقوبة → اطبع عدة صفحات.
3. من «آخر المخالفات» اضغط 🖨️ تنبيه.
4. من ملف السلوك: طباعة تنبيه كتابي.
