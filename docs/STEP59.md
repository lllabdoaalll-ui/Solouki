# STEP 59 — مركز إشعارات WhatsApp

هذه الخطوة تنقل الإشعارات من مجرد فتح WhatsApp Web إلى دورة تشغيل واضحة: تجهيز → إرسال عبر Cloud API → حالة ونتيجة → إعادة محاولة.

## SQL
نفّذ `sql/phase4-step59-whatsapp-notification-center.sql`.

## Edge Function
انشر `supabase/functions/whatsapp-send` واضبط Secret باسم `WHATSAPP_ACCESS_TOKEN`. لا تضع الـ token في ملفات الموقع.

## التشغيل
1. افتح «إشعارات واتساب».
2. اضغط «تجهيز إشعارات اليوم».
3. راجع الطلاب وأرقام أولياء الأمور والرسائل.
4. اضغط «إرسال المعلّق عبر API».
5. راقب الحالات: مجهز، جاري، تم، فشل.
6. في حالة الفشل يمكن فتح WhatsApp يدويًا كبديل، ولا يتم اعتبار ذلك إرسال API ناجحًا.

## ملاحظة Meta
الإشعارات الاستباقية خارج نافذة المحادثة المسموح بها قد تتطلب Message Template معتمدة. هذه الخطوة لا تدّعي نجاح الإرسال إذا رفض مزود WhatsApp الطلب.
