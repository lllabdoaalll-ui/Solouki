# STEP 62 — فلاتر الطلاب وملف الطالب المنبثق

## المطلوب
1. فلتر مرحلة / قسم / صف / فصل في قائمة الطلاب حسب نطاق الصلاحيات.
2. اسم الطالب رابط نشط يفتح نافذة بكل ما يتعلق بالطالب.
3. إمكانية الطباعة من النافذة.

## التنفيذ
- الفلاتر تُبنى من القيم المميزة في قائمة الطلاب المحمّلة (بعد RLS = نطاق الصلاحية).
- الفلاتر مترابطة: اختيار مرحلة يضيّق القسم ثم الصف ثم الفصل.
- الضغط على الاسم أو زر «ملف» يفتح نافذة تفاصيل مع استدعاء get_student_behavior_report إن توفر.
- زر طباعة يطبع بطاقة بيانات أساسية.
