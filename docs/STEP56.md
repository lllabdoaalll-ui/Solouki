# STEP 56 — سجل التدقيق التشغيلي

## الهدف
إضافة سجل مركزي للعمليات الإدارية والتصدير التي ينفذها المستخدم داخل التطبيق، مع قصر القراءة على المسؤول العام.

## SQL
نفّذ: `sql/phase4-step56-audit-log.sql`

## العمليات المسجلة
- إعادة إصدار كلمة مرور موظف.
- تفعيل/إيقاف حساب موظف.
- تعديل صلاحية دور.
- استيراد مستخدمين جماعيًا.
- تصدير الطلاب/المخالفات/التكريمات/JSON.

لا تُسجل كلمات المرور أو المفاتيح السرية.
