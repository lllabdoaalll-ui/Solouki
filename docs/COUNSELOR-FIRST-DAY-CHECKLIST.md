# قائمة تحقق — أول يوم تشغيل للأخصائي (سلوكي)

**المدة المقترحة:** 30–40 دقيقة  
**الحضور:** أخصائي (+ مسؤول حاسب إن أمكن للتجهيز فقط)  
**الهدف:** أن يعتمد الأخصائي على سلوكي في التسجيل والمتابعة والطباعة دون دفتر ورقي كأساس.

---

## أ) قبل الجلسة (مسؤول الحاسب / الإدارة) — 10 دقائق

| تم | البند |
|----|--------|
| ☐ | نشر الإصدار الحالي (4.71.1 أو أحدث) على الموقع |
| ☐ | تنفيذ SQL: مفاتيح التفعيل (STEP 70) + صلاحية السجلات (STEP 71) إن لزم |
| ☐ | حساب الأخصائي يعمل (بريد + كلمة مرور) وتم تجربة الدخول |
| ☐ | صلاحيات الأخصائي مفعّلة: عرض طلاب، تسجيل مخالفات، تسجيل تكريمات، تقارير، **سجلات الرصد** |
| ☐ | يوجد طلاب في النظام (عينة كافية للاختبار) |
| ☐ | أكواد الطلاب محدثة من **ملف القاعدة** (تبويب ملف القاعدة — أكواد) |
| ☐ | ترويسة التقارير مضبوطة (اسم المدرسة / شعارات إن توفرت) |
| ☐ | كتالوج المخالفات فيه بنود مستخدمة فعلياً في المدرسة |

---

## ب) أثناء الجلسة مع الأخصائي — بالترتيب

### 1) الدخول واللوحة (3 دقائق)
| تم | البند |
|----|--------|
| ☐ | فتح الموقع وتسجيل الدخول |
| ☐ | التعرف على بلاطات: مخالفات · تكريمات · طلاب · ملف سلوك · **سجلات الرصد** |
| ☐ | التأكد أن الاسم والدور يظهران بشكل صحيح |

### 2) تسجيل مخالفة (7 دقائق)
| تم | البند |
|----|--------|
| ☐ | فتح **تسجيل مخالفة** |
| ☐ | اختيار طالب من البحث / القائمة |
| ☐ | اختيار بند من **الكتالوج** (وليس وصفاً حراً إن أمكن) |
| ☐ | التأكد أن **الدرجة** ظهرت تلقائياً |
| ☐ | اختيار المكان والتاريخ إن لزم |
| ☐ | حفظ المخالفة والتحقق أنها ظهرت في السجل |

### 3) تنبيه كتابي (إن وُجدت العقوبة) (5 دقائق)
| تم | البند |
|----|--------|
| ☐ | تسجيل مخالفة عقوبتها «تنبيه كتابي» (أو استخدام حالة موجودة) |
| ☐ | طباعة **نموذج التنبيه الكتابي** للتوقيع |
| ☐ | مراجعة أن بيانات الطالب والتاريخ والبند ظاهرة على الورقة |

### 4) تسجيل تكريم (5 دقائق)
| تم | البند |
|----|--------|
| ☐ | فتح **تسجيل تكريم** |
| ☐ | اختيار طالب وكتابة/اختيار التكريم وحفظه |
| ☐ | التأكد أن التكريم يظهر في ملف السلوك لاحقاً |

### 5) ملف سلوك طالب (5 دقائق)
| تم | البند |
|----|--------|
| ☐ | فتح **ملف سلوك الطالب** |
| ☐ | البحث عن الطالب الذي سُجّلت له مخالفة/تكريم |
| ☐ | مراجعة المخالفات + التكريمات + الملخص |
| ☐ | تجربة **طباعة رسمية** لملف السلوك (صفحة واحدة على الأقل) |

### 6) سجل الرصد اليومي (5 دقائق)
| تم | البند |
|----|--------|
| ☐ | فتح **سجلات الرصد** من لوحة التحكم |
| ☐ | اختيار **يومي** + تاريخ اليوم |
| ☐ | (اختياري) تصفية مرحلة |
| ☐ | **عرض السجل** والتأكد أن ما سُجّل اليوم يظهر |
| ☐ | **طباعة أفقية Landscape** ومراجعة الورقة |

### 7) أين باقي الأدوات؟ (دقيقتان — معرفة فقط)
| تم | البند |
|----|--------|
| ☐ | **أسبوعي / شهري / من–إلى** في نفس صفحة السجلات — للاجتماع الأسبوعي ونهاية الشهر |
| ☐ | **إشعارات واتساب** — عند الحاجة لإبلاغ ولي الأمر (ليس إلزامياً أول يوم) |
| ☐ | **دليل المعلمين** — للإدارة لاحقاً؛ ليس من مهام الأخصائي اليومية الآن |

---

## ج) روتين يُتفق عليه في نهاية الجلسة

**يومياً**
1. تسجيل المخالفات والتكريمات وقت حدوثها (أو بنهاية اليوم).
2. طباعة تنبيه كتابي فوراً عند الحاجة للتوقيع.
3. (اختياري) سجل يومي للأرشيف أو التسليم.

**أسبوعياً**
- سجلات الرصد → **أسبوعي** → طباعة لاجتماع السلوك / مدير المرحلة.

**عند طلب الإدارة أو ولي الأمر**
- ملف سلوك الطالب → طباعة رسمية.

## د) ما لا يُطلب من الأخصائي في هذه المرحلة

- ربط معلمي Grade System Pro أو تسجيل من برنامج الرصد  
- استيراد ملفات قاعدة كامل أو إعدادات WhatsApp Business  
- تعديل الصلاحيات أو ترويسة التقارير (إلا إذا كُلّف بذلك)
