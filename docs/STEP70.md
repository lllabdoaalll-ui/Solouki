# STEP 70 — أمان القراءة + مفاتيح تفعيل رصد المعلمين + استيراد نطاق تلقائي

## الهدف
1. إغلاق ثغرة قراءة كل مخالفات المدرسة لأي مستخدم authenticated.
2. تمكين التحكم المركزي في رصد المعلمين حسب المرحلة والقسم دون حسابات Auth للمعلمين.
3. تقليل التدخل البشري: استيراد Excel يملأ النطاق الدراسي تلقائياً.

## ما تم تنفيذه
- سياسة SELECT مقيّدة على `violation_records` و `merit_records`.
- جدول `teacher_behavior_switches` + دالة `teacher_recording_enabled`.
- واجهة تفعيل/إيقاف في `teachers.html`.
- استيراد Excel يفهم عمود «الفصول» ويكتب `teacher_class_assignments`.

## التشغيل
1. نفّذ في Supabase SQL Editor:
   - `sql/phase4-step69-teacher-directory.sql` (إن لم يُنفَّذ)
   - `sql/phase4-step70-security-and-switches.sql`
2. انشر ملفات الواجهة (Vercel).
3. من دليل المعلمين: فعّل المرحلة/القسم المطلوبة، ثم استورد ملف المعلمين.

## صيغة عمود الفصول
```
المرحلة|الصف|الفصل|القسم;المرحلة|الصف|الفصل|القسم
```
مثال: `ابتدائي|1|1|arabic;ابتدائي|2|1|arabic`
