# Solouki 4.62.11

Baseline derived from 4.62.10 after successful manual WhatsApp testing.

## WhatsApp message improvements
- Three distinct message modes: access notice, full written warning, warning + follow-up/escalation steps.
- Full preview modal before any WhatsApp window is opened.
- Preview text can be edited for the current message only.
- Manual bulk sending keeps one named WhatsApp window and requires counselor confirmation before moving to the next student.
- Access notice contains national ID and student code and does not include violation details.
- Full warning uses available violation data; escalation wording does not invent an official escalation level when none is stored.
- Existing fallback preparation from today’s violations is preserved.
